# AutoLogon

Dieser Ordner enthält normalerweise das Tool **Autologon** von Microsoft Sysinternals, das für den automatischen Windows-Login am Release-PC verwendet wird.

Das Tool wird **nicht** in dieses Repository hochgeladen (z. B. aus Lizenz-/Verteilungsgründen). Auf dem Release-PC bleibt die vorhandene Datei einfach liegen.

Für alle anderen: Bitte `Autologon.exe` selbst herunterladen und in diesen Ordner legen.

Download: https://learn.microsoft.com/de-de/sysinternals/downloads/autologon
