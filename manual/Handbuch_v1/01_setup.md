# Setup {#setup}

## Hinweis

Das Setup (Installation, Autostart, Kiosk-Start, Deployment) wird in einem **separaten Programm/Workflow** verwaltet und ist daher hier nur als Platzhalter dokumentiert.

Wenn du Setup-Anpassungen brauchst, prüfe bitte:

- Webserver/Reverse Proxy (z. B. Caddy) und Webroot
- CameraBridge API-Server (Port/Bind/API-Key)
- Python Tool-Server (Port/AuthKey) und Render/Print Dependencies
- Druckerinstallation (Windows) bzw. CUPS/Printer-Setup (Linux)
